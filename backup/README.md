# Backup

Этот каталог описывает проектную структуру системы резервного копирования для `the-hub-infra`.
Здесь собраны документы, шаблоны конфигурации, shell-скрипты и systemd units, необходимые для
будущей реализации.

## Архитектура

Базовый поток данных:

`logical database dumps -> staging -> restic -> external storage`

На этом этапе это только проектная схема. Конкретные параметры, пути и способы доставки ещё должны
быть подтверждены.

## Важное предупреждение

Наличие созданного бэкапа не считается доказанным без тестового восстановления. Для каждого
критичного источника данных нужен отдельный проверенный restore-run.

## Предполагаемая структура временных данных

Пути ниже являются проектными и должны быть подтверждены:

```text
/srv/backups/
├── staging/
│   ├── postgres/
│   ├── sqlite/
│   └── filesystem/
├── logs/
└── restore-test/
```

`/srv/backups/` здесь показан как предполагаемый корень для staging, логов и тестового
восстановления. Фактическое расположение ещё не утверждено.
